# 💐 抽捧花大作戰 • 三竹股市風格多股走勢動畫看盤系統

串接富果 **Fugle Market Data API v1.0**，以三竹股市風格呈現多檔股票分時走勢的競速比價與動畫回放系統。

---

## 🌟 特色亮點

1. **Y 軸股票價格模式**
   - Y 軸真實反映股票交易價格（元），並附設 **`100.00 元黃金基準線`**。
   - 游標懸浮提示（Tooltip）同步顯示即時股價、漲跌額與漲跌幅。

2. **精選 5 檔預設指標股**
   - 預設納入 5 檔台灣熱門指標股與 ETF：
     - **`0050` 元大台灣50**（台灣旗艦藍籌 ETF）
     - **`2317` 鴻海**（全球電子代工與 AI 伺服器龍頭）
     - **`2882` 國泰金**（台灣金控獲利龍頭雙雄）
     - **`0052` 富邦科技**（科技半導體權重旗艦 ETF）
     - **`2301` 光寶科**（電源供應與光電零組件大廠）

3. **動態走勢爭霸與即時排名**
   - 多檔股票走勢同台動態競速，右側即時排名榜支援平滑上下滑動換位動畫，動態呈現超車過程。

4. **可選 5 秒 / 10 秒極速播完**
   - 提供「5 秒播完」與「10 秒播完」切換按鈕。
   - 採用 `requestAnimationFrame` 與高精度時間戳記驅動，流暢播放 5 日共 1,355 根 1分K 資料。

5. **純淨全螢幕比價模式**
   - 支援全螢幕一鍵切換，純淨展示走勢圖表與右側即時排名榜，字體清晰（重點資訊 >= 18px）。
   - 動畫執行完畢後居中彈出冠軍頒獎結算視窗。

---

## 🚀 快速啟動

使用 Python 啟動本機伺服器：
```bash
python server.py
```
或雙擊執行 `start.bat`，即可在瀏覽器開啟 `http://localhost:8080` 體驗！
