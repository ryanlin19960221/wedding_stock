# 💐 抽捧花大作戰 • 三竹股市風格多股走勢動畫看盤系統

串接富果 **Fugle Market Data API v1.0**，以三竹股市風格呈現多檔股票分時走勢的競速比價與動畫回放系統。

---

## 🌟 特色亮點

1. **Y 軸股票價格模式**
   - Y 軸真實反映股票交易價格（元），並附設 **`100.00 元黃金基準線`**。
   - 游標懸浮提示（Tooltip）同步顯示即時股價、漲跌額與漲跌幅。

2. **精選 100 元左右半導體指標股**
   - 預設納入 5 檔台灣百元半導體指標公司：
     - **`8150` 南茂**（半導體封測龍頭）
     - **`6462` 神盾**（指紋辨識與 AI 晶片 IC 設計）
     - **`6756` 威鋒電子**（USB Type-C 高速傳輸晶片）
     - **`4968` 立積**（射頻前端 RF IC 設計）
     - **`6104` 創惟**（USB 高速傳輸控制晶片）

3. **最後一名逆轉奪冠黑馬**
   - **南茂 (8150)** 第 1 天開盤價 89.7 元（落居第 5 名最後一名），隨後一路飆漲至 112.0 元，以 **+24.86%** 勇奪第 1 名冠軍捧花！
   - 右側即時排名榜支援平滑上下滑動換位動畫，動態呈現超車過程。

4. **可選 5 秒 / 10 秒極速播完**
   - 提供「5 秒播完」與「10 秒播完」切換按鈕。
   - 採用 `requestAnimationFrame` 與高精度時間戳記驅動，流暢播放 5 日共 1,355 根 1分K 資料。

5. **純淨全螢幕比價模式**
   - 支援全螢幕一鍵切換，純淨展示走勢圖表與右側即時排名榜，字體清晰（重點資訊 >= 18px）。
   - 動畫執行完畢後居中彈出冠軍頒獎結算視窗。

---

## 🚀 快速啟動

使用 Python 啟動本機伺服器：
```bash
python server.py
```
或雙擊執行 `start.bat`，即可在瀏覽器開啟 `http://localhost:8080` 體驗！
